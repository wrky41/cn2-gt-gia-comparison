## 香港 VPS 的 CN2，到底在说什么

CN2 是中国电信的下一代承载网，但“CN2 VPS”这个词被用得很松。实际买到的东西至少有三种。

第一种是 **CN2 GT**：去程走 CN2，回程走普通 163 骨干。白天看不出问题，晚上八点以后广东、江浙一带的用户最容易感受到差别。这类机器的月付价常常压在 5 美元以下，端口带宽也可能只有 5Mbps 级别——你在一些低价香港套餐的配置表里会看到“5 Mbps 网络速度”这样的写法，它和“CN2”三个字同时出现，并不矛盾，只是带宽和回程都没承诺什么。

第二种是 **CN2 GIA**：双向都走 CN2 的精品线路，晚高峰表现稳定得多，价格也跟着上去。

第三种是三网优化：不只电信，联通走 AS9929、移动走 CMI/CMIN2 也都有优化回程。香港机房做这套的商家不多，因为要和三家运营商都谈线路。GoMami 官方文档写的就是这套组合——电信 CN2、联通 AS9929、移动 CMI 直连，配合根据源 IP 自动选路的智能路由和多上游冗余切换。

延迟方面，官方文档给的典型值是香港到中国大陆 **低于 30ms**、整体 RTT 低于 50ms，并明确标注“实际延迟可能因本地 ISP、时段和网络状况而有所不同”。官方广告页另外给了一组更激进的数字：香港 6ms、日本 30ms、新加坡 36ms，并注明是“三网运营商中最快省份实测数据”。两组数字口径不同，前者是典型值，后者是最好的那个省。看房看样板间，买房看实际层高，道理差不多。

## 常见问题

**香港 CN2 VPS 和香港 CN2 GIA VPS 是一回事吗？**
不是。CN2 是大类，GIA 是其中的双向精品线路，GT 通常只有去程走 CN2、回程走普通线路。三者价格和晚高峰表现差距明显。

**GoMami 香港机房延迟大概多少？**
官方文档给的典型值是香港到中国大陆低于 30ms、整体 RTT 低于 50ms，并注明受本地 ISP 和时段影响。官方广告页另有“香港 6ms”的说法，那是三网中最快省份的实测值。

**Pulse 和 Turin 怎么选？**
看瓶颈在哪。CPU 密集、需要最新平台和更高单核性能，选 Turin；预算优先、主要跑建站和轻量服务，Pulse 更划算。Turin Mini 比 Pulse Mini 贵 10 美元，换来翻倍 NVMe 和 2Gbps 端口。

**流量用完了会怎样？**
